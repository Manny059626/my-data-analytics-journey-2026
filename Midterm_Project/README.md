\# IMDB Data Analytics Midterm Project



\## Project Overview



This project was completed as part of my Data Analytics Bootcamp midterm. The goal was to demonstrate the complete data analysis process using Excel and SQL.



\## Project Objectives



\- Import and assess a messy dataset

\- Clean and transform data in Excel

\- Create Pivot Tables and charts

\- Build a dashboard

\- Import the cleaned data into SQLite

\- Write SQL queries to answer business questions

\- Document the analysis and findings



\## Tools Used



\- Microsoft Excel

\- DB Browser for SQLite

\- SQL

\- Git \& GitHub



\## Files Included



\- \*\*IMDB\_Clean.xlsx\*\* – Cleaned dataset, pivot tables, charts, dashboard, and documentation

\- \*\*messy\_IMDB\_dataset.csv\*\* – Original dataset used for cleaning

\- \*\*IMDB\_Queries.sql\*\* – SQL queries used during analysis

\- \*\*IMDB\_SQL\_Analysis\_Report.docx\*\* – SQL report with explanations and findings

\- \*\*IMDB\_Midterm.db\*\* – SQLite database

\- \*\*IMDB\_Midterm.sqbpro\*\* – SQLite project file
